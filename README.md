# Fast Eraser

Fast Eraser is a private, browser-based tool for removing solid-color image backgrounds and exporting transparent PNGs.

## Features

- Removes edge-connected solid-color backgrounds in the browser
- Strict color matching with adjustable tolerance
- Preserves enclosed foreground details
- Exports transparent PNG files
- No image upload to a server

## Development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
